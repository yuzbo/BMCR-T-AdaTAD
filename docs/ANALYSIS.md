# 当前结论与进一步提高BMCR-T上限的路线

日期：2026-09-11。以下区分本轮观测、解释假设和拟议实验；拟议实验没有被执行，不填入结果表。

## 1. 当前结果究竟支持什么

H65-C / BMCR-T相对官方的矩阵/卷积MAC在S上降低约48.45%，在B上降低约49.55%。这里包括实际执行的CNN/ASFormer、路由相关矩阵计算、VideoMAE、Adapter、检测器和融合注意力QK/AV，不是简单使用384/768推算。

但是，BMCR-T平均mAP相对官方在S/B上仍下降5.86/3.79个百分点（相对下降8.49%/5.32%）。它对H65-C的改善仅0.30/0.73个百分点；S的mAP@0.5和@0.7还分别下降0.42/0.30个百分点，B在五个阈值上均有小幅改善。因此，“提高了均值”不能替换为“边界保持假设已经成立”。单种子结果没有给出稳定性或显著性结论。

同一固定窗口中，官方S/B中位时延51.17/118.17ms，BMCR-T为121.59/153.74ms。当前实现没有表现出速度优势。总时延没有分段归因，不能直接断定ASFormer、Python循环或某个CUDA算子各占多少时间。MAC下降、峰值显存下降、GPU时间、完整服务吞吐、能耗是不同命题。

S受到更大损失的现象在H65-C阶段已经出现；S/B对应损失6.15/4.52个百分点。较小冻结骨干可能更难补偿少观察帧和不规则tubelet带来的信息变化，但这只是解释假设。缺少同日程同K均匀训练对照、多个种子、边界/短动作分层及学习曲线对应的开发集结果，不能断言模型容量是唯一原因。

## 2. 先让改进收益能被解释

优先建立一个新的K384均匀采样、同识别预训练、同20+40课程、同数据增强/优化器/成功更新次数的控制分支；它不是重新训练官方AdaTAD。与H65-C和BMCR-T共享同一预算，判定学习采样的收益或损失。对任何后续模块，固定K与训练预算做单独消融，不用额外帧数、训练时间或更强teacher冒充路由算法收益。

开发集应从200训练视频按视频划分，测试211视频封存。先报告平均mAP、各阈值、动作时长/边界距离/密集重复动作分层，再根据所需结论安排种子重复和按视频重采样的不确定性估计。收敛与调参依据来自开发集，不能在测试集逐轮找最优。

当前交换审计显示原贡献代理与真实收益的留出排序相关较弱且不一致；这说明代理保真度值得研究，不证明BMCR学习效用已经准确。应在BMCR终点、开发视频上检查其实际预测与真实one-swap收益的符号、校准、排序及选择后regret，并比较动作性/覆盖/随机等简单信号。

## 3. 第一条模型路线：让粗特征补充检测证据

已知实现：CNN/ASFormer已经处理全部候选帧，但其hidden主要用于采样，检测器只接收重骨干的所选帧特征。这提供了一个明确可检验的缺口：被丢弃位置的低成本证据没有直接参与检测预测。

先做最小方案：在selected-rank位置收集粗hidden，通过小投影和初始接近零的残差门与细特征融合，加入原始时间、相邻间隔和有效mask。保持K384与检测主头不变，分别比较粗特征辅助监督、直接融合和真正的内容自适应门，避免把额外参数收益当作条件融合创新。

若只融合所选位置仍难恢复短动作，再研究“全时序粗分支＋稀疏细分支”：低成本分支保留原768时间坐标，细分支提供语义/边界残差，用真实时间位置对齐或少量跨注意力融合。需明确特征图尺寸、坐标映射、融合位置、额外头成本以及双分支冲突处理；不能假定已有scout特征对细粒度定位足够好。所有新增计算应进入MAC与同步计时。

跨域借鉴：AdaFocus用低成本全局观察决定高成本局部观察，可借鉴信息分工；其原任务是视频识别，不能直接当作时序检测边界证据。[AdaFocus，ICCV2021](https://openaccess.thecvf.com/content/ICCV2021/html/Wang_Adaptive_Focus_for_Efficient_Video_Recognition_ICCV_2021_paper.html)。CoLT5保留轻计算并将重计算分配给部分token，可启发保留完整低成本状态；它的长文本任务没有THUMOS时间边界标签。[CoLT5，EMNLP2023](https://aclanthology.org/2023.emnlp-main.309/)。

## 4. 第二条模型路线：从效用监督扩展到任务输出自蒸馏

已知实现：当前EMA教师只产生换帧效用，没有监督学生检测logit、边界分布或中间特征。换帧价值预测更准也未必直接恢复被删帧后的检测能力。

先比较同K的互补观察：EMA教师使用覆盖更均匀或独立的K384视图，学生使用学习视图；在真实时间坐标上对齐检测输出，蒸馏分类和边界信息，teacher/匹配/目标全部detach。需要处理不同proposal、缺失实例和置信度，避免把错误teacher边界强制传给学生。与当前utility-only、no-KD、相同额外teacher计算的控制组比较。

更高预算EMA教师是单独的下一步：先明确可共享参数与随K变化的时间状态、位置编码及Adapter几何，再低频运行；完整记录训练额外计算，不把它记作推理计算。官方B到S属于跨模型蒸馏，应单独命名；不要把“使用更强官方教师”与“自模型自蒸馏”的证据混在一起。

可借鉴同网络深层到浅层的监督与不同观察视图的上下文化目标，但任务和对齐问题须重新定义：[Be Your Own Teacher，ICCV2019](https://arxiv.org/abs/1905.08094)、[data2vec 2.0，ICML2023](https://proceedings.mlr.press/v202/baevski23a.html)。不预设堆叠feature、logit、relation、boundary、utility五种损失会更好；先验证一种直接对应当前失败模式的监督。

## 5. 第三条路线：非线性决策与真实时间几何一起改

必须先区分四件事：①候选位置在时间上不均匀；②内容到采样概率的非线性函数；③已选集合/预算条件下的交互决策；④离散决策的梯度估计。当前模型已经包含非线性MLP/ASFormer、固定预算校准与非均匀取帧；“再加一个非线性层”本身不是新机制。

优先检查间隔信息：当前真实时间回映发生在检测几何中，冻结VideoMAE的tubelet仍按打包顺序处理输入。可以比较显式Δt/跨度/密度位置特征、保持clip内规则运动而只学习clip中心的采样、带覆盖约束的单调时间变换，以及针对非均匀观察的轻量时间融合。需要同时说明是否改变K、信息量、骨干结构和预训练分布。

然后研究集合决策：当前只在16候选cell内找最近相反成员伙伴，标签在S0上测量，最终集合却经过全局预算重新解码。可先校准这种局部目标能否预测最终集合收益，再比较覆盖/多样性条件、局部候选交互、少量迭代修正或排序目标。增加修正次数必须受实测时延约束。

AdaFrame可提供序列决策/未来观察效用的参考，但识别的奖励并不等价于检测边界召回。[AdaFrame，CVPR2019](https://openaccess.thecvf.com/content_CVPR_2019/html/Wu_AdaFrame_Adaptive_Frame_Selection_for_Fast_Video_Recognition_CVPR_2019_paper.html)。Deformable DETR围绕参考位置学习少量采样点，可借鉴坐标和内容共同决定取样，但它在已计算的图像特征上采样，不能直接算作跳过RGB骨干的成本。[Deformable DETR](https://arxiv.org/abs/2010.04159)。SampleNet的可微点云采样可启发task-conditioned选择与软/硬匹配；其混合点松弛并不直接保证选到真实视频帧，需保留本任务exact-K/hard-gather合同。[SampleNet，CVPR2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Lang_SampleNet_Differentiable_Point_Cloud_Sampling_CVPR_2020_paper.html)。

## 6. 性能上限与执行速度并行诊断

先在同一块卡、同一输入/精度下分段计时scout、伙伴构造、率校准/解码、gather、VideoMAE/TIA、检测与回映，再做固定权重的执行优化。源码中的逐cell控制流是应被测量的候选热点，不是已经定量确认的瓶颈。任何向量化或融合应验证所选帧和预测保持一致，再报告时延变化。

阶段顺序建议：预算匹配对照与终点效用诊断 → 粗细融合最小分支 → 真实时间对齐的输出自蒸馏 → 时间几何/集合决策。它们可先分别验证，再组合；空间/深度三维扩展应在单轴证据成立后讨论。目标是找到可解释的精度—真实计算折中，不是为BMCR名称保留预设结论。

以上文献是机制检索起点，不是完整最新综述，也没有把其他任务的收益移植为本项目预测数字。外部讨论应继续检索近年原始论文和官方源码，尤其寻找反例、负结果和比这些起点更近的方法。
