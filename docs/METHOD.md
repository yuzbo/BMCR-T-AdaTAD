# BMCR-T：定义与实际边界

BMCR来自研究报告中的 **Boundary-aware Conditional Marginal Compute Routing**；T表示仅实现时序部分。本次将两份报告的条件效用、真实换帧监督与H65机制整合到纯净OpenTAD AdaTAD核心。它是研究提案的实现和检验，不是某个已给定论文公式/官方仓库的逐项数值复刻。

## 共同核心

低分辨率RGB CNN和ASFormer观察全部768候选位置，预测动作性与转变信息。固定预算率解码器把该信号转为384个真实观察位置，严格有序；有效长度不足384时全选有效帧，其余物理槽位填充并置无效。重骨干实际从48个16帧clip降为24个，保留单视频内全局TIA交互。VideoMAE非Adapter参数冻结，但仍实际执行其前向计算。

当前检测器接收selected-rank特征，GT先映射到该坐标；预测在NMS之前回映真实时间，再采用完整视频聚合与类别SoftNMS。回映是分段线性的几何变换，不等于补回未观察帧的信息，也没有自动修复VideoMAE tubelet内的不规则运动间隔。

## H65-C

H65-C同时预测分类/回归贡献分布。监督来自均匀companion行上的 `mean(abs(input * gradient))`，插值到候选格点，再用温度0.7的分布交叉熵学习。批内一半行使用均匀采样，其余行使用学习采样。它保留了梯度敏感性，但不是有符号的真实换帧收益。

## BMCR-T

1. 仅从转变先验生成初始集合S0；BMCR分支不再执行H65-C的贡献头。
2. 对每个候选构造条件特征：自身与显式互换伙伴hidden、已选集合均值、转变表示、是否已选、伙伴距离、两侧覆盖间隙、动作概率、有效K/T。伙伴是同一16候选cell内最近的相反成员身份位置。
3. 小型两输出头预测标准化的分类/定位效用。对可行位置将两个分量等权平均，按unit gain加到转变分数，只修正一次，再用相同固定预算解码器选帧。
4. 联合训练的反馈预热结束后，每8次成功更新尝试EMA教师监督；在学习采样行上测量S0以及至多两次可行交换。教师eval/no_grad，目标detach。查询包含已选和未选候选；只有伙伴互为对应时才添加互反标签。

若i已选、j为其未选伙伴，保留i的目标为 `L(S0-i+j)-L(S0)`，正值表示移除i更差。对未选候选，插入收益符号相反，并且必须针对其自己的显式伙伴。分类目标使用固定基线指派/归一化；定位目标使用原始时间预测与GT的实例匹配、IoU/边界距离和漏检代价。固定与重新匹配的诊断量均被记录。

两个目标按仅来自训练视频审计的分量尺度归一化，用Huber损失监督；最大附加权重0.1，按课程逐步开启。EMA decay为0.999。教师并不在推理期存在，也未做检测logit或特征蒸馏。CNN/ASFormer粗特征目前用于选帧，没有直接融合到检测器。

## 不能由结构直接保证的性质

- 有限one-swap标签不是Shapley值或整个集合的全局最优边际收益。
- 标签在S0测量，最终检测器使用修正后的集合；这是当前设计，是否产生有害分布错配需要实证。
- 固定预算与代理梯度合同测试通过，不意味着离散集合目标具有无偏梯度或已经最优。
- “Boundary-aware”描述监督考虑真实时间定位和边界代价，不是高tIoU性能已经保持的证明。
- T版本没有增加空间token压缩、深度跳层或三维联合预算；不能把报告中未实现部分的预期收益归给本次模型。
