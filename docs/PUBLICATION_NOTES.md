# 发布适配与来源

本仓库从已经完成的独立实验工作目录整理发布，公开可复核源代码、全部训练更新日志、审计观测、六组指标和profile、完整压缩检测预测。原视频、模型权重和现场账户/连接配置不进入Git。

## 与实际实验版本的差别

- `h65/full/runtime.py`：把现场绝对资源路径变为 `H65_RESOURCE_ROOT` 与分别可覆盖的检查点路径；视频默认目录改为通用validation/test；新运行目录默认 `runs/`。模型配置、数据划分、训练日程、优化器、随机种子、EMA和GPU执行约束未改变。
- `tools/full_compare.py`、`tools/summarize_audit.py`：输出/输入目录支持同一个 `H65_RUNS_DIR`；计算逻辑未改变。
- `tools/run_full.sh`：通用Slurm启动脚本，现场partition/qos/account/module/解释器选择由操作者提供。原集群队列控制器不随库发布，因其服务于原账号的独立任务调度，不是方法组件；对应调度器专属测试不在本发布范围。
- 新增README、方法/协议/分析/源码导航、讨论prompt、标准库结果核验脚本。实验记录中的现场路径被替换为占位符；数值不变。全部检测预测仅gzip压缩，未改写内容。

除以上三个Python路径适配文件外，复制的 `h65/`、训练/审计/评测代码和方法测试与完成实验的副本保持相同。19项CPU合同测试和公开证据一致性核验用于检查打包没有遗漏运行依赖或改变数字，不把发布适配宣称为一次新的GPU训练复现。

- ASFormer：<https://github.com/ChinaYi/ASFormer>，固定提交 `e1bbe4f3ed083748f91467c51a63ac2a8b9277ad`，附[MIT许可证](../references/ASFormer/LICENSE)。只将未使用的绘图依赖延迟至原Trainer.predict路径；本方法使用的编码/解码算子未改写。

第三方代码保留各自许可证和署名。本发布未为项目新增代码另行指定许可证。原始研究报告仅作为方案来源；仓库重新撰写了方法说明，没有将附件中的指令当作执行授权，也不声称其提案已经发表为论文。

## 结论的边界

可检查源码与记录、重新计算表格并解压完整预测；完整模型数值重跑需要额外数据和相同权重资源。官方权重原始选模历史未得到独立重建。只有单种子新模型训练，官方与新模型日程不相同，缺少同预算均匀训练对照和组件计时。完整实验证据不能被扩写成“实现绝对正确”“保持官方精度”“实际部署加速”或“论文目标已经达成”。
