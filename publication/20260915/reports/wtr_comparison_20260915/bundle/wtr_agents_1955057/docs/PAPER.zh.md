# 论文构建：Where to Refine

工作标题：**Where to Refine: Learning the Marginal Value of Computation for Temporal Action Detection**。

本文框架是研究计划，不是已完成结果稿。不得把已实现/入队转换成性能结论。论文成立的最低条件不是“六个模块都能运行”，而是预算内真实任务收益、可解释的机制对照和可复核的成本。

## 1. 主张与证据的对应关系

| 拟议主张 | 必须提供的证据 | 当前不能替代它的材料 |
|---|---|---|
| 被测TAD系统存在可利用的计算冗余 | 同模型的输入保留算子干预、组合干预；独立适配后质量—成本曲线；预先设定非劣效界限 | 相邻特征余弦高、单个frame删去不掉loss |
| 非均匀分配值得学习 | 同预算随机/均匀/静态/GT辅助搜索/learned的完整检测比较 | Gini高；只胜random；有限greedy未找到增益 |
| 学到的是条件计算价值 | 真实RGB/算子重执行效用与预测的配对检验；heldout regret与mAP | repair feature substitution；attention magnitude |
| 轻计算分支保留了任务状态 | 相同pre-operator输入下的残差误差与任务损失；同mask的前后TIA分析 | 单纯最终feature MSE；模块名字带light |
| 原时间轴访问机制必要 | 同选帧、相同T/D/S masks、相同训练监督，比较Cross/时间注意力/稀疏边 | 同时更换selector、teacher、KV和decoder的总分差 |
| 未来价值有用 | 固定动作库，earlier/current预测later实际价值；current/EMA/lagged/future等算力对照；实际部署增益 | PCA低秩；两个checkpoint数值相减；β=1冒充EMA |
| 三轴有效 | 固定轴因子+同成本对比+实际路由曝光；解释不选择D/S的样本 | Full配置命名；V2-S高分但几乎所有窗D100/S100 |
| 方法更高效 | 矩阵/卷积成本与真实延迟分别报告、decode/NMS范围明示、训练额外查询计账 | token访问数或FLOPs单一指标 |

## 2. 摘要草稿（未完成实验不使用结果时态）

时序动作检测需要同时识别动作并定位其起止时刻。降低视频骨干的计算开销具有实际意义，但视频的视觉重复不等于边界定位所需的信息冗余。本文首先通过受控的观测与算子干预，研究不同时间、空间位置和网络深度的计算是否具有可利用的任务边际价值差异。我们将一项计算的价值定义为在当前证据与执行状态下，该项计算对检测目标带来的条件改善，而不是将其等同于显著性、注意力或重建误差。在此基础上，我们研究一个保留原始时间坐标的预算计算框架：逐帧分配昂贵观测，区分关系访问与非线性状态更新，并通过受任务监督的反事实收益训练计算价值预测器。针对轻重执行路径的表示偏移，我们比较同输入算子对齐与完整轨迹监督；针对计算价值随训练变化的问题，我们检验从自身历史轨迹外推教师并进行蒸馏的有效性。实验将围绕均匀分配的竞争力、真实计算成本、定位误差和跨设置泛化展开。最终稿仅在实验完成后填入数据集、mAP差值、置信区间、成本和时延；Graph与未来价值蒸馏只有通过独立机制验证后才列为贡献。

## 3. 引言五段

**目标与未知。** 从降低TAD部署成本开始。不宣称所有TAD均匀dense attention，也不宣称所有视频存在可删除的固定冗余比例。说明被研究参考系统和其具体成本结构。

**经验反证与问题深化。** 当前H65逐帧选择具有一定低成本性能，但A-MoD附加压缩明显伤害检测，且S的好结果大量避开D/S。这说明“能选少量帧”不等于“任意减少后续计算都安全”。由此提出是否需要按状态/算子定义价值。

**概念分解。** 从Uni-AdaFocus借鉴廉价预览与重计算分工；从GM借鉴状态、访问与更新的区分。这里不是宣称新增cheap scaffold：H65已存在Scout、Cross和原轴回写。要证明新的分配依据、对齐方式或访问机制增益。

**学习难题。** 数据提供动作标签，但不直接标注每个执行决策的收益。真实反事实昂贵，局部attention只是代理，价值随模型/预算变化。RISE提供轨迹外推教师的灵感，但必须重新验证TAD价值预测；非平稳性本身并不推出线性外推有效。

**贡献。** 限定为三项：任务条件的计算诊断；状态保持的算子/逐帧价值分配；通过验证的教师构造与优化。某项失败就删除或改为负结果，不围绕模块数量写贡献。

## 7. 成稿的条件

最终候选、预算、teacher来源和checkpoint选择规则先冻结；代码/资产hash完整；已有关键80轮课程收尾；等预算强uniform、独立原版K384、至少一条外部泛化完成；若只有FLOPs下降而延迟上升，标题和摘要明确为计算量折中而非实测加速。未获三轴互补证据时，题目可以保留“计算价值”，正文不得声称统一三轴优越性已证实。
