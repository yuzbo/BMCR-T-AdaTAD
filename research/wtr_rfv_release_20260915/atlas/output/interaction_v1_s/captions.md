conditional_value_interaction
Four GT-blind fixed-count local-choice triplets per window, frozen AdaTAD-S. T re-runs the same physical-location rule after an RGB swap; D/S exchanges use disjoint legal positions. The diagonal is additivity; positive/negative residuals denote super/subadditivity of these specified changes. CDFs weight videos equally. Symmetric-log axes use a 1e-8 display core; this is not a statistical threshold. Replay controls use eight identical executions at the first local baseline; a zero band may collapse. Exceeding that scale is neither statistical significance nor evidence that a joint allocator is required. Triple values remove all lower-order terms.

interaction_matrix
Normalized total-loss interaction, video-balanced summaries and 95% video-cluster bootstrap intervals. Background color encodes signed mean only; E|I| and the exceedance percentage expose cancellation. Percentages exceed an empirical replay reference, not a significance or practical-effect threshold. With replay epsilon=0, tiny nonzero values may exceed the reference; use the actual magnitudes. T pairs include eligible windows only; D×S covers all 211 videos.

conditional_choice_regret
The same fixed-count local cubes as the primary interaction analysis. In (a,b), S/D gains before and after T use the same baseline denominator and a remapped fixed rule. Orange means strictly positive two-choice reference regret, including tiny effects; no significance threshold is implied. In (c), A→B means choose B using its actual baseline-context value, then reuse that choice after A changes. The alternative is the measured best of the same two feasible choices in the new context. This is a finite actual-value diagnostic, not a trained router or learnability result; positive regret CIs are descriptive. T-related pairs use 187 eligible videos, DS uses 211. Axes have different choice granularity, so directional magnitudes do not establish an optimal ordering theorem.

temporal_spatial_context
T uses the first predeclared local frame exchange; D is full. S sparse uses checkerboard 50% heavy FFN at four routed layers; S full uses all heavy FFN. This comparison changes S cost and is not a matched-cost superiority claim. Panels (a-c) use T-eligible windows; panel (d) includes all videos with explicit identity fallback where T is inapplicable. AP interactions recompute all four dataset APs on the same 10000 video draws. Regret compares the baseline-context binary choice with the actual best of the same two choices under the changed context. No learned router or global budget optimum is evaluated.

interaction_cases
Descriptive examples selected at 10/50/90 percentiles of video-mean |T×D interaction|, with the median-|T×D| cube inside each selected video. Maps show only measured coordinates; blank regions were not queried. Gray intervals are GT action intervals, used only for annotation. Waterfalls reconstruct the actual eight-cell joint gain from three first-order, three pairwise and the pure third-order term. Rounded tables use the displayed axis multiplier; full-precision normalized terms are in case_values.json and numeric_tables.md. These are sampled local exchanges, not continuous time×layer value fields.

appendix_interaction_strata
Exploratory total-loss interaction strata from the same GT-blind local bank. Intervals are unadjusted 95% video-cluster bootstrap intervals, not paired between-stratum tests. GT relation labels the baseline coordinate and includes partially visible action intervals; it was not used to select measurements. Conditional video populations and counts vary across regions and are reported in numeric_tables.md. Layer and region comparisons do not establish boundary dominance or a causal layer effect.
